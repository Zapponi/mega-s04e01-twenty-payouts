# Checklist

Rules every role keeps. One line each, with the Challenge it came from. Add new ones after each debrief.

1. Bind each secret to the hosts it may reach, in code, and check every hop, redirects included. (S04E01)
2. Run routine work as a script; the model decides only what the script cannot. (S04E01)
3. Turn the rules in any document you read into checks, and park the owner’s calls instead of making them. (S04E01)
4. Have every role read its facts (settings, prices, limits) from their source at every start; never copy them into its files. (S04E02)
5. Write down why each decision exists, next to the code, and have every role read those notes before it judges or changes anything. (S04E02)
